# Rota Inteligente

**Entregas mais rápidas, com inteligência artificial.**

O **Rota Inteligente** é um estudo de otimização de entregas para um serviço de
delivery: ele encontra os caminhos de menor custo pela cidade e agrupa as
entregas próximas em zonas de atendimento — menos deslocamento, mais entregas
no horário de pico.

## O que ele faz

- **Calcula as melhores rotas** entre o ponto de saída e cada destino,
  considerando distância e tempo.
- **Agrupa entregas próximas** em zonas, para dividir melhor o trabalho entre
  os entregadores.
- **Gera mapas e gráficos** para visualizar as rotas e as zonas.

## Situação

Projeto acadêmico da disciplina de Fundamentos de Inteligência Artificial,
desenvolvido sobre um caso de estudo fictício.
